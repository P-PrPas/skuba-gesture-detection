# CLAUDE.md

Monorepo of independent gesture-detection projects — see `README.md`.

- Each project folder (`GPSR-GD/`, `Waving-GD/`) is self-contained and has its own
  `README.md`; `GPSR-GD/` also has a `CLAUDE.md`.
- Work in the folder the task is about, run commands from inside it, and do not
  import across project folders.
- `GPSR-GD/` is archived — don't change it unless explicitly asked. Its `CLAUDE.md`
  rules (fixed backbone, no hand-written thresholds, etc.) apply to GPSR-GD only,
  **not** to `Waving-GD/`.
- `Waving-GD/` is the active project; its own architecture is decided as work starts.
