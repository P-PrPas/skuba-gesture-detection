# Waving-GD — Gesture Detection for Waving

Detect whether a person is waving. Single-gesture detection (waving vs. not
waving), unlike the multi-class `../GPSR-GD/`.

**Status:** just started — no code yet.

`../GPSR-GD/` (MediaPipe Pose + Hands backbone, keypoint normalization, camera/
multi-person demo) is available as a reference for reusable pieces; copy what's
needed into this folder rather than importing across folders.
